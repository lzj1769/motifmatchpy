Result types¶

Import these types from motifmatchpy, for example from motifmatchpy import Variant. They are immutable dataclasses. Match also supports unpacking into pos, score. See coordinate conventions before interpreting indel results.

motifmatchpy._types.Match dataclass ¶

Match(pos: int, score: float)

A motif occurrence: where it starts, and what it scored.

motifmatchpy._types.Variant dataclass ¶

Variant(start_pos: int, end_pos: int, modified_seq: str = '')

A sequence edit: [start_pos, end_pos) replaced by modified_seq.

end_pos == start_pos + 1 with a one-character replacement is a substitution, end_pos == start_pos an insertion, and an empty modified_seq a deletion.

motifmatchpy._types.MatchWithVariant dataclass ¶

MatchWithVariant(pos: int, score: float, variants: tuple[int, ...] = ())

An occurrence that exists only once some variants are applied.

pos is relative to the modified sequence, and variants holds indices into the variant list that was handed to the scanner.
