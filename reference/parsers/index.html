Matrix parsers¶

These functions read numeric matrices and ADM terms. They do not parse a multi-motif JASPAR/MEME database. See file formats.

motifmatchpy.parsers ¶

Matrix file parsers.

Two formats are understood, both plain whitespace-separated numbers:

.pfm A JASPAR-style count matrix: one row per symbol (A, C, G, T), one column per motif position.

.adm An adjacent dinucleotide model: a * a rows of first-order conditional terms, followed by a rows giving the zero-order terms for the first position.

read_table ¶

read_table(filename: str | PathLike[str]) -> list[list[float]]

Read whitespace-separated numbers into a list of rows.

A row stops at the first token that is not a number, and rows holding no numbers at all are dropped -- so blank lines and comment lines disappear rather than becoming empty rows. This mirrors how the C++ reader consumes a line with a stream of double extractions.
